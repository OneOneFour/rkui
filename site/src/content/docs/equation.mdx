A site that uses these components installs `katex`. With the default `rkui()` setup, rkui's
stylesheet comes first and KaTeX's rules beat its maths styles, so the site sets
`head: { styles: false }` and imports the stylesheets itself, KaTeX's first:

```js
import 'katex/dist/katex.min.css'
import '@oneonefour/rkui/styles.css'
```

The TeX goes in the `tex` attribute. A TeX error stops the build.

<Demo label="Display equation" stack>
  <Equation
    id="eq-flow"
    tex="\frac{\mathrm{d}\mathbf{x}}{\mathrm{d}t} = \mathbf{f}(\mathbf{x};\, \sigma, \rho, \beta) \tag{1}"
  />
</Demo>

## Frames

`variant` sets the frame: `panel`, `rule` or `key`.

<Demo label="Equation frames" stack>
  <Equation variant="panel" tex="\dot{x} = \sigma (y - x)" />
  <Equation variant="rule" tex="\dot{y} = x (\rho - z) - y" />
  <Equation
    variant="key"
    tex="\lambda = \lim_{t \to \infty} \frac{1}{t} \ln \frac{\lVert \delta \mathbf{x}(t) \rVert}{\lVert \delta \mathbf{x}(0) \rVert}"
  />
</Demo>

## Numbers

`\tag{n}` numbers an equation. A tag on each row of an `align` numbers every row; one tag after an
`aligned` block numbers the block once.

<Demo label="Equation numbers" stack>
  <Equation tex="\begin{align*} \dot{x} &= \sigma (y - x) \tag{2} \\ \dot{y} &= x (\rho - z) - y \tag{3} \\ \dot{z} &= x y - \beta z \tag{4} \end{align*}" />
  <Equation
    id="eq-lorenz"
    tex="\begin{aligned} \dot{x} &= \sigma (y - x) \\ \dot{y} &= x (\rho - z) - y \\ \dot{z} &= x y - \beta z \end{aligned} \tag{5}"
  />
</Demo>

## References

`EquationReference` links to an equation by its `id`. `long` adds an icon and the word "Equation".

<Demo label="Equation references" stack>
  <p>
    Pack my box with <EquationReference to="eq-flow" number="1" /> five dozen liquor jugs.
  </p>
  <p>
    <EquationReference to="eq-lorenz" number="5" long /> judges my vow, beside a short{' '}
    <EquationReference to="eq-lorenz" number="5" />.
  </p>
</Demo>

## Colour-coded terms

`\teal{…}`, `\coral{…}` and the other palette hues each tint a term.

<Demo label="Colour-coded terms" stack>
  <Equation tex="\frac{\partial E}{\partial t} = \teal{-\nabla \cdot \mathbf{F}} + \coral{Q} - \navy{\varepsilon}" />
</Demo>

## Long equations
