KaTeX turns the TeX into HTML when the page is built, so the page runs no maths JavaScript. A site
that uses these components installs `katex` and loads its stylesheet before rkui's:

```js
import 'katex/dist/katex.min.css'
import '@oneonefour/rkui/styles.css'
```

Write the TeX in `tex` as a quoted attribute, which keeps backslashes, braces and underscores as
they are. In MDX the slot would be Markdown, which changes them. A TeX error stops the build.

<Demo label="Display equation" stack>
  <Equation
    id="eq-flow"
    tex="\frac{\mathrm{d}\mathbf{x}}{\mathrm{d}t} = \mathbf{f}(\mathbf{x};\, \sigma, \rho, \beta) \tag{1}"
  />
</Demo>

## Try it

Type TeX to see it render. This demo runs KaTeX in the browser, so this page loads its
JavaScript; a page with only `Equation` and `Maths` loads none. While the TeX has an error, the
error shows under the box and the equation stays as it last rendered.

<Demo vue={tryItCode} label="Equation that renders as you type" stack widget>

</Demo>

## Frames

The bare equation is the default. `variant` puts it on a `panel`, beside a `rule` down the
left, or on a raised dashed panel, `key`, for a key result.

<Demo label="Equation frames" stack>
  <Equation variant="panel" tex="\dot{x} = \sigma (y - x)" />
  <Equation variant="rule" tex="\dot{y} = x (\rho - z) - y" />
  <Equation
    variant="key"
    tex="\lambda = \lim_{t \to \infty} \frac{1}{t} \ln \frac{\lVert \delta \mathbf{x}(t) \rVert}{\lVert \delta \mathbf{x}(0) \rVert}"
  />
</Demo>

## Numbers

`\tag{n}` numbers an equation. A tag on each row of an `align` numbers every row; one tag after an
`aligned` block numbers the block once.

<Demo label="Equation numbers" stack>
  <Equation tex="\begin{align*} \dot{x} &= \sigma (y - x) \tag{2} \\ \dot{y} &= x (\rho - z) - y \tag{3} \\ \dot{z} &= x y - \beta z \tag{4} \end{align*}" />
  <Equation
    id="eq-lorenz"
    tex="\begin{aligned} \dot{x} &= \sigma (y - x) \\ \dot{y} &= x (\rho - z) - y \\ \dot{z} &= x y - \beta z \end{aligned} \tag{5}"
  />
</Demo>

## References

`EquationReference` links to an equation by its `id`, as a pill like the equation's number. The
equation it jumps to flashes. `long` leads with an icon and the word, for the start of a sentence.

<Demo label="Equation references" stack>
  <p>
    Pack my box with <EquationReference to="eq-flow" number="1" /> five dozen liquor jugs.
  </p>
  <p>
    <EquationReference to="eq-lorenz" number="5" long /> judges my vow, beside a short{' '}
    <EquationReference to="eq-lorenz" number="5" />.
  </p>
</Demo>

## Colour-coded terms

`\teal{…}` puts the hue's tint behind a term. Teal, yellow, navy, green, sky, coral, grape,
tangerine, lilac and apricot each have one.

<Demo label="Colour-coded terms" stack>
  <Equation tex="\frac{\partial E}{\partial t} = \teal{-\nabla \cdot \mathbf{F}} + \coral{Q} - \navy{\varepsilon}" />
</Demo>

## Long equations

An equation too wide for the column scrolls sideways (see [Scroll](../scroll/)). Tab to it and use
the arrow keys, or swipe. `dots="pill"` puts the dots at its edges in pills.

<Demo label="Long equation" stack>
  <Equation tex="\frac{\partial u}{\partial t} + u \frac{\partial u}{\partial x} + v \frac{\partial u}{\partial y} + w \frac{\partial u}{\partial z} - f v = -\frac{1}{\rho} \frac{\partial p}{\partial x} + \nu \left( \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} + \frac{\partial^2 u}{\partial z^2} \right) \tag{6}" />
</Demo>
