A full-width band that opens a page: a kicker line over the page's heading, and a hard rule along
its foot. It takes the page's section hue, so it shows which part of the site the reader is in;
`hue` picks a colour instead. The slot holds the heading, at the level that fits the page, and an
optional line under it.

## The page's section hue

A site sets `--rkui-section` and `--rkui-on-section` once for each part of the site, on the page
or its `<body>`. The band, checked chips, section buttons, breadcrumbs and table bands all take it.
For coral, set `--rkui-coral-solid` and `--rkui-on-coral`, as small text sits on it.

## In a site frame

The band with a Sidebar beside it: the plain look on a sky panel, in slab type with bold links,
where each link has its section's colour (`hue`) and an icon, and the current one is filled with
it. When the frame is narrow and the nav stacks above the page, its links flow into columns
(`columns`). The frame
itself is the site's own layout, a few lines of CSS grid in the example's `<style>`: the nav column
beside the page, stacked above it when the frame is narrow. On a real page the column would also
be `position: sticky` with a `max-block-size` of `100dvh`, so it scrolls on its own.
