`Card` is an `<article>` with a title and a body. On its own it is a static panel. With `href` the whole card is one link: the title is the link text, and there is a single tab stop.

<Demo label="A static card">
  <Card title="Field notes" meta="Updated today" style="inline-size: 20rem">
    <p>Pack my box with five dozen liquor jugs.</p>
  </Card>
</Demo>

## Static edges

A static card never lifts, but it needs an edge, or it vanishes on a raised surface such as this demo's. It has an outline by default; `variant` picks one of the others: `raised` (the outline and a hard shadow that doesn't lift), `shaded` (a panel fill with no outline) or `inset` (pushed into the page). Each is shown here in light and in dark, on the page colour.

## Image

The `image` slot sits above the body. Give it an `<img class="rkui-card-image">`, or any element with that class.

## Shadow colour

`hue` takes a palette hue or a hex code, such as a colour from the card's image. With the colour shadow (`data-shadow="color"`) in dark mode, a linked or raised card casts that colour's shade instead of the lighter grey; light mode and the other shadows are unchanged. This demo always has the colour shadow.

      <p>Static, so it never lifts.</p>

## Heading level

`headingLevel` (2, 3 or 4) sets the title's heading, to fit the page outline. It is 3 when left out.

<Demo label="Cards with heading levels">

      <p>An h2 title.</p>
    </Card>
    <Card title="Level 4" headingLevel={4} style="inline-size: 12rem">
      <p>An h4 title.</p>
    </Card>
  </div>
</Demo>
