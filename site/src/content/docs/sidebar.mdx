Groups of links, each a child component. The page gives the sidebar its height; when its links
don't fit, it scrolls, with hints at its edges and a scrollbar on hover and focus. `variant`
picks the look.

## F: Sections

A sky panel for a site's own navigation. Each link takes `color`, the section hue of the page it
leads to: it fills the link's icon, and the link itself when it is the current page. The `header`
slot stays above the links, for the site's name and tagline. A group needs no heading. When the
panel is wide, the links flow into columns. The [header band](../header-band/) page shows it in a
site frame.
