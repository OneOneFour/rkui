Each `Tab` is one tab, and the rest of the slot is the sheet. Mark the tab that's showing
`selected`; the first is when none is. For tabs that switch panels, see Tabs.

<Demo label="Folder" stack>
  <Folder label="Example">
    <Tab label="One" />
    <Tab label="Two" />
    <Tab label="Three" />
    <p>The sheet.</p>
  </Folder>
</Demo>

## Tinted

Add `tinted` for a sheet in the selected tint.

<Demo label="Tinted folder" stack>
  <Folder label="Tinted" tinted>
    <Tab label="One" />
    <Tab label="Two" />
    <Tab label="Three" selected />
    <p>The sheet in the selected tint.</p>
  </Folder>
</Demo>

## Narrow

When the tabs don't fit, the strip scrolls, with dots at the edge that has more. It has no
scrollbar, which would come between the tabs and the sheet.

<Demo label="Narrow folder" stack>
  <Folder label="Narrow" style="max-inline-size: 16rem">
    <Tab label="Tab one" />
    <Tab label="Tab two" selected />
    <Tab label="Tab three" />
    <Tab label="Tab four" />
    <p>Too narrow for its tabs, so the strip scrolls.</p>
  </Folder>
</Demo>
