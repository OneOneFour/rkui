Each `Tab` is one tab, and the rest of the slot is the sheet. Mark the tab that's showing
`selected`; the first is when none is. For tabs that switch panels, see Tabs.

## Narrow

When the tabs don't fit, the strip scrolls. Its scrollbar sits above the tabs, where a normal one
would come between the tabs and the sheet.
