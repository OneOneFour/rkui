Each `Tab` is one tab, and its slot is that tab's panel. Click a tab, or move between them with the
arrow keys. The first tab starts selected; mark another `selected` to start there. Each tab is a
native radio, so Folder needs no JavaScript.

    <Tab label="One">
      <p>Panel one.</p>
    </Tab>
    <Tab label="Two">
      <p>Panel two.</p>
    </Tab>
    <Tab label="Three">
      <p>Panel three.</p>
    </Tab>
  </Folder>
</Demo>

## With v-model

In a `.vue` file, `v-model` is the selected tab's index, so the widget can read and set it.

The widget below is rendered with `client:visible`.
