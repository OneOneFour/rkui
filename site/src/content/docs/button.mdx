## Busy

`busy` starts a button in its busy state: it fills with water, is marked `aria-busy` and
`aria-disabled`, and stays focusable. Say what is happening in the label.

<Demo label="Busy buttons">
  <Button busy>Saving…</Button>
  <Button busy color="teal">
    Saving…
  </Button>
  <Button busy color="navy">
    Saving…
  </Button>
  <Button busy color="coral">
    Saving…
  </Button>
  <Button busy color="grape">
    Saving…
  </Button>
</Demo>

## Busy at a level

`level` holds the water at a fixed height from 0 to 1, for a wait with known progress. It works
with `busy` or `water`.

<Demo label="Busy buttons at a level">
  <Button busy color="teal" level={0.25}>
    Uploading<span class="rkui-visually-hidden"> 25%</span>
  </Button>
  <Button busy color="teal" level={0.5}>
    Uploading<span class="rkui-visually-hidden"> 50%</span>
  </Button>
  <Button busy color="teal" level={0.85}>
    Uploading<span class="rkui-visually-hidden"> 85%</span>
  </Button>
</Demo>

## Busy from a script

`water` includes the water without starting busy, so a script can set `aria-busy` later. Click the
button to toggle it. A busy button does not stop its own clicks; the script decides what to ignore.
