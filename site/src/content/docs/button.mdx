`toggle` makes a button that stays pushed in while it is on.

## Pressed

A button with `aria-pressed="true"` is pushed in the same way. Its script flips the value on each
click.

<Demo vue={pressedCode} label="Buttons with aria-pressed" widget>
  <PressedButtons client:visible />
</Demo>

Use `toggle` for an on/off choice that is part of a form: it works with no JavaScript, submits
with the form, and screen readers hear a checkbox. Use a button with `aria-pressed` when a script
holds the state, such as showing or hiding part of the page: screen readers hear a toggle button.
