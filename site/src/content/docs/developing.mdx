A component is a `.vue` file and a `.css` file beside it, in `src/components/<name>/`. Its CSS
joins the list in `src/index.css`, and its docs page goes in `site/src/content/docs/`. The examples
on this page live in `site/src/examples/developing/`, so they import the library by its package
name.

## A static component: Definition

A dictionary entry: the word across the column, its pronunciation and part of speech under it,
and its meaning.

### 1. Props and template

`interface Props` lists the props, each with a comment saying its default. The word's length goes
to the CSS as a custom property, from a `computed`.

### 1. One part

`LampPart` is one outlined shape on a grid, in a palette hue. Its `hue` goes through `hueVars()`,
which turns a hue or a hex code into the fill's custom property.

### 3. Make it interactive

`ExplodedLamp` holds whether the lamp is apart in a `v-model` (`defineModel()`), and binds it to a
`Switch`. The switch does nothing until the component runs, so it stays hidden until
`onMounted` sets `data-rkui-live`.
