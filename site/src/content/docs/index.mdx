## Using rkui

### Astro

Add Vue to the site (`npx astro add vue`). A site that uses CodeBlock also installs `shiki`
(`^4.0.0`), an optional peer. Add this line to `src/env.d.ts`, so `astro check` accepts the
attributes rkui components hand on to their native elements:

```ts
/// <reference types="@oneonefour/rkui/astro-attributes" />
```

In the layout, import the stylesheet, inline the head scripts at the top of `<head>`, and import
`enhance.js` in a script at the end of `<body>`:

- `theme-init.js` applies the stored light or dark theme before the page paints;
- `table-init.js` holds back a table's entrance until it plays;
- <a id="helper-scripts"></a>`enhance.js` loads every helper script (`*-enhance.js`).

```astro
---
// src/layouts/Layout.astro
import '@oneonefour/rkui/styles.css'
import themeInit from '@oneonefour/rkui/head-scripts/theme-init.js?raw'
import tableInit from '@oneonefour/rkui/head-scripts/table-init.js?raw'
---

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <script is:inline set:html={themeInit} />
    <script is:inline set:html={tableInit} />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>My site</title>
  </head>
  <body>
    <slot />
    <script>
      import '@oneonefour/rkui/enhance.js'
    </script>
  </body>
</html>
```

A component that runs in the browser, such as Stepper, gets `client:visible`.

```astro
<Stepper client:visible label="Quantity" value="3" />
```

### Fenced code and maths in MDX

rkui's Astro integration renders, in MDX files, a fenced code block as CodeBlock, `$…$` as Maths and
`$$…$$` as Equation. It needs `shiki` for the code and `katex` for the maths, with KaTeX's
stylesheet loaded before rkui's ([Equation](equation/)).

```js
// astro.config.js
import { defineConfig } from 'astro/config'
import mdx from '@astrojs/mdx'
import vue from '@astrojs/vue'
import rkui from '@oneonefour/rkui/astro'

export default defineConfig({
  integrations: [mdx(), vue(), rkui()],
})
```


- A fence's language is CodeBlock's `lang` (`plaintext` when there is none), and the rest of its
  first line is the `label`.
- `rkui({ code: { copy: 'hover' } })` gives every fence's CodeBlock those attributes; `code: false`
  or `maths: false` turns either off.
- `\$` is a dollar sign in text.
- An equation that an EquationReference links to is written as a tag, with an `id`:
  `<Equation id="eq-flow" tex="…" />`.
- `.md` files are left as they are.

### Plain HTML

Copy the package's `dist/` folder into the site. Paste `theme-init.js` and `table-init.js` (from
`src/head-scripts/`) inline at the top of `<head>`, link `rkui.css`, and load `rkui.js`, which holds
the helper scripts and the custom elements, such as `<rkui-stepper>`.

```html
<head>
  <meta charset="utf-8" />
  <script>
    /* theme-init.js, pasted in */
  </script>
  <script>
    /* table-init.js, pasted in */
  </script>
  <link rel="stylesheet" href="vendor/rkui/rkui.css" />
  <script type="module" src="vendor/rkui/rkui.js"></script>
</head>
```

### A Vue app

Import the stylesheet and the helper scripts in the app's entry, and paste the head scripts into
`index.html` as a plain page does.

```js
// src/main.js
import '@oneonefour/rkui/styles.css'
import '@oneonefour/rkui/enhance.js'
```
