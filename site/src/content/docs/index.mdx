## Using rkui

### Astro

Add Vue to the site (`npx astro add vue`). A site that uses CodeBlock also installs `shiki`
(`^4.0.0`), which highlights the code: it is an optional peer, so npm leaves it out. Add this line
to `src/env.d.ts`, so `astro check` accepts the form and link attributes rkui components hand on to
their native elements:

```ts
/// <reference types="@oneonefour/rkui/astro-attributes" />
```

In the layout, import the stylesheet, inline the head scripts at the top of `<head>`, and import
`enhance.js` in a script at the end of `<body>`:

- `theme-init.js` applies the reader's stored light or dark choice before the page paints;
- `table-init.js` keeps a table that is in view on load blank until its entrance plays;
- <a id="helper-scripts"></a>`enhance.js` loads every small helper script: browser fallbacks and
  small extras for the components that need no JavaScript.

```astro
---
// src/layouts/Layout.astro
import '@oneonefour/rkui/styles.css'
import themeInit from '@oneonefour/rkui/head-scripts/theme-init.js?raw'
import tableInit from '@oneonefour/rkui/head-scripts/table-init.js?raw'
---

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <script is:inline set:html={themeInit} />
    <script is:inline set:html={tableInit} />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>My site</title>
  </head>
  <body>
    <slot />
    <script>
      import '@oneonefour/rkui/enhance.js'
    </script>
  </body>
</html>
```

An interactive component, such as Stepper, gets `client:visible`; without it, it renders its
markup and stays still. Every other component ships no JavaScript.

```astro
<Stepper client:visible label="Quantity" value="3" />
```

### Fenced code and maths in MDX

rkui's Astro integration renders Markdown's own syntax in MDX files with rkui's components, with no
tags to write: a fenced code block as CodeBlock, `$…$` as Maths and `$$…$$` as Equation. The site
installs `shiki` for the code and `katex` for the maths, and loads KaTeX's stylesheet before
rkui's ([Equation](equation/)).

```js
// astro.config.js
import { defineConfig } from 'astro/config'
import mdx from '@astrojs/mdx'
import vue from '@astrojs/vue'
import rkui from '@oneonefour/rkui/astro'

export default defineConfig({
  integrations: [mdx(), vue(), rkui()],
})
```

- A fence's language is CodeBlock's `lang` (`plaintext` when there is none), and the rest of its
  first line is the `label`.
- Each fence's CodeBlock gets `client:visible`, for its copy button.
- `rkui({ code: { copy: 'hover' } })` gives every fence's CodeBlock those attributes, and
  `code: false` or `maths: false` leaves fences or dollars as Markdown has them.
- `\$` is a dollar sign in text.
- An equation that an EquationReference links to needs an `id`, so it is written as a tag:
  `<Equation id="eq-flow" tex="…" />`.
- The integration adds a plugin to Sätteri, Astro's Markdown processor, on `markdown.processor`,
  which MDX inherits. With `mdx({ processor })` or `mdx({ extendMarkdownConfig: false })`, MDX has
  a processor of its own, so fences and dollars stay as they are and the build warns: move those
  plugins to `markdown.processor` instead. `.md` files are left as they were, dollars included.

### Plain HTML

Copy the package's `dist/` folder into the site. Paste `theme-init.js` and `table-init.js` (from
`src/head-scripts/`) inline at the top of `<head>`, link `rkui.css`, and load `rkui.js`, which
holds the helper scripts and the custom elements, such as `<rkui-stepper>`.

```html
<head>
  <meta charset="utf-8" />
  <script>
    /* theme-init.js, pasted in */
  </script>
  <script>
    /* table-init.js, pasted in */
  </script>
  <link rel="stylesheet" href="vendor/rkui/rkui.css" />
  <script type="module" src="vendor/rkui/rkui.js"></script>
</head>
```

### A Vue app

Import the stylesheet and the helper scripts in the app's entry, and paste the head scripts into
`index.html` as a plain page does.

```js
// src/main.js
import '@oneonefour/rkui/styles.css'
import '@oneonefour/rkui/enhance.js'
```
