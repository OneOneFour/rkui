`WidgetTabs` goes inside a `.vue` file, where every panel is Vue content. Each `WidgetTab` is one
tab, and its slot is that tab's panel; `v-for` works. Click a tab, or use the arrow keys, Home and
End. `v-model` is the selected tab's index, so the widget can read and set it. In an Astro or MDX
page, use [Tabs](../tabs/); WidgetTabs stops the build there.

The widget below is rendered with `client:visible`.

<Demo vue={defaultCode} label="Widget tabs" stack widget>
  <TopicTabs client:visible />
</Demo>
