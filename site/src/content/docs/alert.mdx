closes it.

## An answer it must have

With `closedby="none"`, Escape leaves it open, so one of its buttons must close it. The button's
`value` becomes the dialog's `returnValue`, which a script reads on its `close` event. `autofocus`
starts focus on the safer button.

<Demo label="Alert that waits for an answer">
  <Button command="show-modal" commandfor="alert-answer">
    Delete
  </Button>
  <Alert id="alert-answer" title="Delete for good?" closedby="none">
    <p>Pack my box with five dozen liquor jugs.</p>
    <Fragment slot="actions">
      <Button unfilled command="close" commandfor="alert-answer" value="keep" autofocus>
        Keep
      </Button>
      <Button color="coral" command="close" commandfor="alert-answer" value="delete">
        Delete
      </Button>
    </Fragment>
  </Alert>
</Demo>

## From a script

A script opens an alert with `document.getElementById('alert-basic').showModal()`, as it would
call `alert()`, and closes it with `close()`.
