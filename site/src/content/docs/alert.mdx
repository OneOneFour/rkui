The button opens the alert; Escape closes it.

<Demo label="Alert with one button">
  <Button command="show-modal" commandfor="alert-basic">
    Open
  </Button>
  <Alert id="alert-basic" title="Unsaved changes">
    <p>Pack my box with five dozen liquor jugs.</p>
    <Button slot="actions" command="close" commandfor="alert-basic">
      OK
    </Button>

</Demo>

## An answer it must have

With `closedby="none"`, Escape leaves it open, so one of its buttons must close it.

<Demo label="Alert that waits for an answer">
  <Button command="show-modal" commandfor="alert-answer">
    Delete
  </Button>
  <Alert id="alert-answer" title="Delete for good?" closedby="none">
    <p>Pack my box with five dozen liquor jugs.</p>
    <Fragment slot="actions">
      <Button unfilled command="close" commandfor="alert-answer" value="keep" autofocus>
        Keep
      </Button>
      <Button hue="coral" command="close" commandfor="alert-answer" value="delete">
        Delete
      </Button>
    </Fragment>
  </Alert>
</Demo>

## From a script

A script opens an alert with `showModal()` and closes it with `close()`. The closing button's
`value` becomes the dialog's `returnValue`.
