The code goes in the slot. Code longer than a line goes in as a string: `{{ code }}` in a `.vue`
file, `{code}` in Astro and MDX.

## Highlighting

A site that uses CodeBlock installs `shiki`. `lang` is a Shiki language id.

<TextToCome />

## No title area

Leave out `label`: the copy button sits in the code's corner.

<Demo vue={noTitleCode} label="Code block with no title area" stack>
  <NoTitle client:visible />
</Demo>

## Copy on hover

With `copy="hover"`, the copy button shows while the pointer is over the block.

<Demo vue={hoverCode} label="Code blocks whose copy button shows on hover" stack>
  <Hover client:visible />
</Demo>

## No copy button

With `copy="never"` there is no copy button.

<Demo vue={noCopyCode} label="Code block with no copy button" stack>
  <NoCopy />
</Demo>

## Editor tab

`editor` puts the caption in a darker strip on a flat panel, like an editor's tab.

<Demo vue={editorCode} label="Code block with an editor tab" stack>
  <Editor client:visible />
</Demo>

## Long lines

A long line scrolls sideways (see [Scroll](../scroll/)). `bar` keeps the scrollbar in view.

<Demo label="Code block with a scrollbar that stays" stack>
  <CodeBlock lang="shell" copy="never" bar>
    {`echo "A long line of code that does not wrap, so the block scrolls sideways and keeps its scrollbar in view"`}
  </CodeBlock>
</Demo>
