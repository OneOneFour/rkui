The code goes in the slot, and is trimmed. A short line can be written as it is
(`<CodeBlock lang="shell">npm install</CodeBlock>`). Vue, Astro and MDX all tidy the white space
in text written between tags, so longer code goes in as a string, which keeps every space and line
break: `{{ code }}` in a `.vue` file, `{code}` in Astro and MDX.

## Highlighting

Shiki highlights the code when the page is built, on the server, so the page ships no highlighter.
`lang` is a Shiki language id; one Shiki doesn't know is shown as plain text. Shiki's
`css-variables` theme marks each token with a CSS variable, which `code.css` maps onto the
`--rkui-code-*` colour tokens, so the colours follow the theme and the light or dark mode. A site
that uses CodeBlock installs `shiki`. In the browser the block never highlights: one that a Vue
app draws there, or whose code changes there, shows plain text.

## Copy on hover

With `copy="hover"`, the copy button rolls in from the top while the pointer is over the block,
or focus is inside it. On a touch screen it is always there.

## Long lines

A long line scrolls sideways, with dots at the edges; `dots="pill"` puts them in pills (see
[Scroll](../scroll/)).
`bar` keeps the scrollbar in view instead, with no dots; a plain HTML page writes it as the class
`rkui-scroll--bar` on the `<pre>`.

<Demo label="Code block with a scrollbar that stays" stack>
  <CodeBlock lang="shell" copy="never" bar>
    {`echo "A long line of code that does not wrap, so the block scrolls sideways and keeps its scrollbar in view"`}
  </CodeBlock>
</Demo>

## Language mark

The caption starts with a mark for the language: the site's logo in the `logo` slot, else the
library's file-type icon for the language, else the file extension as text. rkui holds no brand
logos. These docs take theirs from the `simple-icons` package, drawn in the caption's flat grey,
as the demo at the top of the page does, so a site without them shows the file-type icon or the
extension text instead. A fence that the Astro integration renders
([Getting started](../#fenced-code-and-maths-in-mdx)) has no logo slot, so it always shows the
icon or the extension.
