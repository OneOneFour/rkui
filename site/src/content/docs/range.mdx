## Ticks

`ticks` lists the values to mark under the slider. It needs `client:visible`.

<Demo label="Range with ticks" stack>
  <Range client:visible label="Volume" step="25" ticks={[0, 25, 50, 75, 100]} />
</Demo>

## Showing the value

`value-display` shows the value in the thumb (`thumb`) or in a popup over it (`popup`, `flat-popup`). It needs `client:visible`.

<Demo label="Value in the thumb" stack>
  <Range
    client:visible
    label="Opacity"
    value-display="thumb"
    min="0"
    max="1"
    step="0.01"
    value="0.28"
  />
  <Range
    client:visible
    label="Volume"
    value-display="thumb"
    step="25"
    ticks={[0, 25, 50, 75, 100]}
  />
</Demo>

<Demo label="Value in a popup" stack>
