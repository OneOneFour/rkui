Every scrollbar on the page takes the toon colours, a yellow thumb on a raised track, in the
browser's own shape. Scroll is for the page's own wide content, such as a table or a diagram: a
region the keyboard can reach and scroll, named for screen readers. Three dots at each edge show
there is more to see, and a toon scrollbar, a pill track with an outlined thumb, shows on hover and
focus. Code blocks, folder tabs, tables and sidebars have the same scrolling built in, so they
don't need wrapping.

## Plain or pill dots

`dots="pill"` puts the dots in a raised pill that slides in from the edge. To give the whole site
pills, set `data-rkui-dots="pill"` on `<html>` or a container instead: sidebars, code blocks, folder
tabs and tables take it too, and `data-rkui-dots="plain"` switches back inside it.
